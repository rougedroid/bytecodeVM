# BytecodeVM

A small bytecode virtual machine written in C.

## Files

- `vm_main.c` — Main VM implementation entry point.
- `vm_main_1.c` — Alternate or experimental VM entry point.

## Usage

Compile with a C compiler, for example:

```sh
gcc -o bytecodevm vm_main.c
# or
# gcc -o bytecodevm vm_main_1.c
```

Run the generated executable and provide any required bytecode input as defined by the project.
